### Who I am

Second-year CS undergrad at DY Patil International University, also pursuing a BS in Data Science from IIT Madras. I don't just study AI — I deploy it. From a voice reception bot running on Raspberry Pi to ML pipelines for industrial sensor data, I build things that work in the real world, not just in notebooks.

What makes me different: I get from idea to working system fast, I'm comfortable across the full stack — hardware to LLMs — and I've built for real users who actually needed the solution.

### Experience

**AI/ML Intern · Infotact Solutions** `2025 · Ongoing`

IoT Predictive Maintenance project using the AI4I 2020 dataset. Part of a 4-member team building an end-to-end ML pipeline for industrial machine failure prediction.

- Feature engineering: Z-score normalization, risk flag generation from sensor readings
- EDA module: time-series plotting functions, statistical analysis using UDI as time proxy
- Wrote the production README; contributed to team GitHub workflow across multiple branches

`Python` `pandas` `scikit-learn` `Jupyter` `Git`
